# illustrator-scripts

Adobe Illustrator 用のスクリプト集です。

## 処理状況

スクリプトの実行中は処理状況ウィンドウが表示されます。複数の項目を処理するスクリプトでは、進捗も表示されます。処理が完了すると結果がダイアログで通知され、エラーやキャンセルの場合もメッセージが表示されます。

## スクリプト

### エリア内文字・サイズ自動に変換

`scripts/エリア内文字・サイズ自動に変換.jsx` は、選択したポイント文字を、テキスト量に合わせてサイズが自動調整されるエリア内文字へ一括変換します。

#### 使い方

1. Illustrator でポイント文字を選択します。
2. **ファイル > スクリプト > その他のスクリプト...** を選択します。
3. `エリア内文字・サイズ自動に変換.jsx` を選択して実行します。

実行後、変換されたテキストの個数がダイアログに表示されます。選択範囲にポイント文字がない場合は、変換対象がないことを知らせるメッセージが表示されます。

#### 注意事項

- 実行前にオブジェクトを選択してください。
- ポイント文字以外のオブジェクトや、すでにエリア内文字になっているテキストは処理されません。
- Illustrator の「自動サイズ調整」設定は、スクリプト実行前の状態に戻されます。

### アートボードを数値分拡大

`scripts/アートボードを数値分拡大.jsx` は、現在のアートボードを入力した数値だけ各辺から拡大します。入力値の単位にはドキュメントの定規の単位を使用します。

#### 使い方

1. Illustrator で拡大したいアートボードをアクティブにします。
2. **ファイル > スクリプト > その他のスクリプト...** を選択します。
3. `アートボードを数値分拡大.jsx` を選択して実行します。
4. ダイアログに拡大する数値を表示されたドキュメントの単位で入力します。

入力した数値が各辺に加算されるため、幅と高さはそれぞれ数値の2倍分大きくなります。

### アートボードと同じサイズの四角形を作成

`scripts/アートボードと同じサイズの四角形を作成.jsx` は、現在のアートボードと同じ位置・サイズの四角形を作成します。

#### 使い方

1. Illustrator で対象のアートボードをアクティブにします。
2. **ファイル > スクリプト > その他のスクリプト...** を選択します。
3. `アートボードと同じサイズの四角形を作成.jsx` を選択して実行します。
